# 08 · References

**What this folder is:** the inbox, filed — every useful reel, post, website and resource the owner ever sent, organised so it can be found again. This is the raw material the rest of the repo was distilled from.

## Files
| File | What it is |
|---|---|
| `reels-and-resources-index.md` | The map: 301 indexed entries in archive order. **Search here first.** |
| `saved-references-part-1.md` … `part-5.md` | The full archive text, in order. Each entry carries its creator, link, key points, and relevance |
| `websites-and-resources.md` | The standing websites: design libraries, free domains, free hosting, free learning, AI services — each with what it is actually for |

## How entries are filed (the evidence rule)
Every entry is labelled by how it was verified — audio- and caption-verified, frame-verified, screenshot-verified, or a creator's claim filed AS a claim. Nothing is guessed: if a detail could not be read cleanly, the entry says so. When you reuse something from here, respect its label — a creator's "one prompt builds everything" is marketing until you test it.

## How to use this folder
- **Starting work on a topic?** Search the index for it first (responsive design, scroll effects, deployment, hackathons, SEO…) — there is probably a filed item, and the distilled version may already live in `../01-design-system/` or `../05-tools/`.
- **Found something new?** File it the same way: creator, link, date, key points, evidence label, relevance. Then distil anything reusable into the matching general folder.
