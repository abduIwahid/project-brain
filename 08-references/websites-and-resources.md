# Websites & resources

Standing references, each with what it is actually for. The full filed archive (295 indexed reels/posts/resources) is in `saved-references-part-*.md` in this folder, mapped by `reels-and-resources-index.md`.

## Design references
- **ui-layouts.com** (+ cursify.ui-layouts.com) — component & effect library; the standing first check before building any component. Verdicts: `../01-design-system/ui-layouts-library.md`.
- **getlayers.ai** — finished websites published as full build prompts; the mega-prompt method (`../07-prompts/mega-prompt-method.md`).
- **is-it-vibecoded.vercel.app** — slop-score checker for AI-built sites; a vibe check, not a verdict.
- **Context.dev** — design-token extraction from reference sites (styleguide tool) + web/company data APIs.

## Free domains & hosting
- **is-a.dev** — free dev subdomain via GitHub PR (is-a-dev/register).
- **runs-on.dev** — free name with real DNS records (CNAME/TXT), works with Vercel custom domains.
- **nic.eu.org** — free domains since 1996; slow, manual, bring nameservers.
- **dash.domain.digitalplat.org** (DigitalPlat FreeDomain) — free names under shared roots (.dpdns.org, .us.kg, .qzz.io...); fine for tests, never for identity.
- **Render / UptimeRobot** — free backend + keep-awake pings.
- **Vercel / GitHub Pages / Cloudflare Pages** — free hosting tiers used in production here.

## Free learning
- **NASA Open Science training** — science.nasa.gov/open-science/training (free certificates).
- **roadmap.sh**, **free-for-dev** (GitHub) — roadmaps and the free-tier index.

## AI services used
- **Groq** — fast open-model inference (free tier, per-minute token caps).
- **Google AI Studio / Gemini** — model API keys for prototypes.
- **Hugging Face** — models, datasets, Spaces hosting.
