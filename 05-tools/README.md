# 05 · Tools

**What this folder is:** the bench — every tool categorised by job, so "what should I use for X?" has a standing answer.

## Files, and when to use each
| File | What it is | When to use it |
|---|---|---|
| `tools-by-job.md` | The master list by job: design, frontend, backend/hosting, database, quality/SEO/audit, free domains, free learning — plus a few long-established free resources | **Start here** when picking a tool for anything |
| `agent-skills-toolbox.md` | The AI-agent toolbox: 10 verified GitHub repos (Ponytail, Hallmark, Impeccable, Graphify, Scrapling, Humanizer, Diagram Design, last30days, REA, /taste) with what each one does | When setting up an AI-assisted workflow or looking for a capability an agent should have |
| `free-stack.md` | The free-tier stack the owner's projects actually run on | When scoping a project to cost nothing |
| `devops-toolchain.md` | The 12-tool DevOps pipeline map (Git → GitHub → CI → Docker → Kubernetes → IaC → GitOps → observability) with the owner's current position and learning path | When planning DevOps/MLOps learning or a project's delivery pipeline |

## How tools get added
A tool earns its place by being used in a real project, or by passing a vetting pass (real, maintained, genuinely useful — a star count is not a verdict). The weekly upkeep of the parent repo adds new finds here.
