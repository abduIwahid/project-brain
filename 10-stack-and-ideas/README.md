# 10 · Stack & Ideas

**What this folder is:** who is building, and what might get built next.

## Files
| File | What it is | When to use it |
|---|---|---|
| `my-stack.md` | The owner's actual stack — languages, ML/data, frontend, backend, DevOps — and his specialisations (explainable AI, healthcare ML, full-stack products around models) | Scoping a project ("can this be built with what's already known?"), writing a CV or proposal, or picking project-appropriate tools from `../05-tools/` |
| `future-projects.md` | The idea backlog: projects and features noted for later | When choosing what to build next. An idea graduates by getting a brain (`../07-prompts/project-brain-prompt.md`) — not by being started casually |

## A note on ideas
An idea in `future-projects.md` is a note, not a commitment. When one is picked up, it goes through the same brain-first, audit-last process as everything else in this repo.
