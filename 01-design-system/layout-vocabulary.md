# Layout vocabulary (for briefing AI coding agents + design discussions)

From @davidm_ai's "Types of Web Page Layouts" (saved-references item 91).
Naming the pattern gets a precise structure instead of a vague page:

- **Single Column** — one vertical stack; docs, articles, mobile-first pages.
- **Two Column** — content + sidebar (or two balanced halves).
- **Grid Layout** — uniform cards in rows/columns (project galleries).
- **F-Pattern** — text-heavy pages scanned top + left (blogs, search results).
- **Z-Pattern** — eye path Z across the page; light landing pages, hero + CTA.
- **Split Screen** — two contrasting halves (two audiences / before-after).
- **Magazine** — mixed-size editorial grid, featured story + smaller items.
- **Asymmetrical** — deliberately uneven weights for energy/focus.
- **Holy Grail** — header + footer + left nav + content + right rail.
- **Masonry** — staggered-height tiles (Pinterest-style feeds).
- **Hero Landing** — full hero section on top, content below (his portfolio).
- **Full-Screen** — one viewport-tall immersive section, no scroll fold.

## Reading patterns (@brandingbybhawika, saved-references item 143)

Design for how eyes actually move: F-pattern on text-heavy/search pages
(scan across the top, then down the left — front-load headings and left
columns); Z-pattern on simple landing pages/posters (top-left → top-right
→ diagonal → bottom-right — put the CTA at the end of the Z); Markings on
lists/directories/reports (the eye holds one spot while scrolling — the
fixated column must carry the key identifier, e.g. name + status); Layer-
Cake on docs/articles (headings are skimmed first — headings alone must
tell the story).

## Menu-icon names (vamshi.work, saved-references item 145)

Hamburger = 3 equal lines (nav drawer). Kebab = 3 vertical dots
(contextual/overflow menu). Veggie Burger = 2 equal lines. Strawberry =
3 centred lines shrinking downward (filter/sort). Stairs = 3 left-aligned
lines shrinking downward (filter/sort). Candy Box = 3×3 dot grid (app
launcher). Use the names in feedback and prompts so the pattern is exact.

## Six "boring hero" alternatives (appsketch.ai, saved-references item 289, 2026-11-23)

The default hero (headline + button left, product image right) works but nobody remembers it. Six named alternatives, each with its best-fit case:
1. **Marquee Hero** — giant scrolling text behind/over a stack of photos. Best for: Gen Z brands, showing fresh drops.
2. **Colour Switch Hero** — the whole page's colour changes with the selected product colour; size picker + add-to-bag live inside the hero. Best for: single-product stores with colour variants.
3. **Stat Hero** — bold headline with a proof number up top (e.g. "+21%"). Best for: products where results are the main character (SaaS, tools, case-study-led).
4. **Bold Type Hero** — oversized type + ONE image + a contrasting highlighted keyword. Best for: brands with a loud personality.
5. **Wardrobe Hero** — products hang on a rail; scroll, tap, zoom. Best for: fashion lines with a limited catalogue.
6. **Basic But Not Basic** — a dark, moody full-bleed photo with a huge headline on top. Best for: premium brands that sell on trust.
