## Strengths
- The best-organised small repo he has: consistent structure, a verify
  link per certificate, stats tables — it does the one job (prove the
  credentials) properly.
- Verification links make it genuinely useful to recruiters; most
  students just post images with no proof path.

- Incomplete: the Programming Hub AI/ML Developer certificate is
  missing, so the repo quietly under-reports him.
- Stale contact email undermines the "professional reference" purpose.
- Manual upkeep: every new certificate needs image + folder README +
  table + badge + stats edits in several places — the kind of friction
  that makes collections silently go stale (last updated May 2026).
- No LICENSE needed here (personal documents) — not a weakness, just
  don't add one blindly.
