171. **Font Weight Guide** (@gfx.om; cover-verified, single-image infographic, "Design Smarter" series) — https://www.instagram.com/p/Dey7CV5z6kJ/
   25 Oct 2026. A complete one-page reference on building hierarchy from ONE family's weights instead of more fonts. The scale: Thin 100 (decorative, premium brands), Extra Light 200 (subtitles, captions), Light 300 (body text, UI, airy designs), Regular 400 (paragraphs, general use), Medium 500 (subheadings, key points, callouts), Semi Bold 600 (headlines, emphasis, buttons), Bold 700 (titles, section headers, important info), Extra Bold 800 (hero text, posters, strong branding), Black 900 (short text, large displays only). Pairing recipes: Clean & Modern = Regular + Medium; Bold & Clear = Regular + Bold; Elegant & Premium = Light + SemiBold; Minimal & Clean = Regular + Light; Impact & Power = Bold + Black. Rules: use 2–3 weights max in a single design; heavy weights for headings/key elements, lighter for body/secondary; keep clear contrast BETWEEN weights; never make important text too thin, never set long paragraphs in heavy weights, test at different sizes (mobile readability called out). Relevance to Abdul Wahid: this sheet is the theory behind a bug he hit the same evening — Anton ships ONE weight (400), so bold utility classes on it synthesized a faux-bold that looked wrong across WhyRisk, which is why headings moved to Archivo (a true multi-weight family) and Anton became display-only. His locked system already follows the guide's shape (Archivo 400 body / 500–600 UI emphasis / 700 headings; Anton reserved for Extra-Bold/Black-tier display moments). Joins his @gfx.om typography set (items 117 Font Pairing, 132 Best Fonts for Logos, 154 Colour Psychology, 163 Font Anatomy) and is a ready-made page for the planned Design Rules Handbook repo's typography section. Distilled into brain/general/frontend-preferences.md.
